An entry for make.fun's "One Line, One Laugh" bounty: `main.py` checks a single joke sentence against the house rules (plain UTF-8, one line, at most 200 characters) and writes it to `/output/entry.txt` with no trailing newline. That one sentence is the entire entry.

## How to run

```sh
python3 main.py
```

The script prints how many characters it wrote. It needs nothing beyond Python 3 and the standard library.
